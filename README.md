# oxDb

oxDb is an early software prototype associated with the FanCradle / Alethia
concept: a founder-focused network of reusable expert systems. The project
document describes a platform where business knowledge is turned into expert
systems, AI helps execute practical workflows, and blockchain-based identity,
payments, governance, and rewards provide a transparent protocol for
contributors.

The proposed platform is organized around four layers:

- **Knowledge:** research, playbooks, case studies, interviews, and best practices.
- **Expert systems:** reusable guidance for marketing, sales, operations, finance,
	hiring, compliance, and other business functions.
- **Execution:** workflows such as website creation, lead qualification, customer
	support, publishing, and reporting.
- **Protocol:** identity, reputation, governance, payments, licensing, and
	contributor incentives.

The long-term vision includes a marketplace where businesses use expert systems
and contributors can share in the value they help create. The accompanying
document also discusses Ethereum integration, creator-owned transactions, and
liquidity and treasury principles.

## Current implementation

The repository is a small prototype, not yet the complete platform described in
the project document. Its Rust component defines a blog record and demonstrates
storing and retrieving JSON-serialized records in Redis. The wider expert-system,
marketplace, AI execution, and blockchain workflows are described as project
direction rather than implemented features here.
